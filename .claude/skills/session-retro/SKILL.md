## 振り返りの3つの質問

この順に自問して答える:

- 今回、最初の想定より時間がかかった箇所はどこか?
- それは「知識があれば即解決できた定番問題」だったか?
- 次回のために、どんなスキル(またはCLAUDE.mdへの追記)があれば防げたか?

## 記録先と形式

`docs/retro/YYYY-MM-DD.md` に以下の形式で残す:

```markdown
# 振り返り YYYY-MM-DD
## やったこと(1〜2行)
## 回り道(あれば)
- 症状 / かかった時間 / 本当の原因 / 次回への対策
## スキル候補
- <スキル名案>: <一言で>
```

## 基準

回り道が「2回目」になったものは必ずスキル化を提案する。
1回目はメモだけでよい(なんでもスキル化すると読む物が増えすぎる)。

## 実例

2025-06-09のiOS音声問題は、90分の回り道が
後日の分析で10個のスキル提案になった。セッション直後なら5分で同じ成果が出せた。
