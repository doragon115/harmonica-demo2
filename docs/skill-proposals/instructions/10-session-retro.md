# 指示書10【優先度★】session-retro スキルの作成

## 目的

作業セッションの終わりに「今回どこで回り道したか」を1分で振り返り、
次のスキル候補を記録として残す。このスキル提案書自体を生んだ活動を仕組み化する。

## 背景

今回の分析は事後に git 履歴と md5 から軌跡を復元して行ったが、
セッション直後なら記憶が新しく、もっと正確に安く振り返れる。
回り道は繰り返す前にスキル化するのが最も効率がよい。

## 作成するファイル

`.claude/skills/session-retro/SKILL.md`

## フロントマター(このまま使う)

```markdown
---
name: session-retro
description: 大きめの作業が一段落した時、またはユーザーに「振り返って」「今日の作業をまとめて」と言われた時に読む。回り道の記録と次のスキル候補の抽出。
---
```

## SKILL.md 本文に含める内容(全部入れる)

1. **振り返りの3つの質問**(この順に自問して答える):
   - 今回、最初の想定より時間がかかった箇所はどこか?
   - それは「知識があれば即解決できた定番問題」だったか?
   - 次回のために、どんなスキル(またはCLAUDE.mdへの追記)があれば防げたか?

2. **記録先**: `docs/retro/YYYY-MM-DD.md` に以下の形式で残す:

   ```markdown
   # 振り返り YYYY-MM-DD
   ## やったこと(1〜2行)
   ## 回り道(あれば)
   - 症状 / かかった時間 / 本当の原因 / 次回への対策
   ## スキル候補
   - <スキル名案>: <一言で>
   ```

3. **基準**: 回り道が「2回目」になったものは必ずスキル化を提案する。
   1回目はメモだけでよい(なんでもスキル化すると読む物が増えすぎる)。

4. **実例**(このまま載せる): 2025-06-09のiOS音声問題は、90分の回り道が
   後日の分析で10個のスキル提案になった。セッション直後なら5分で同じ成果が出せた。
