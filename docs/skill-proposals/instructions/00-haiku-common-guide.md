# 【Haiku向け】全スキル共通ガイド — 最初に必ず読むこと

これは Claude Haiku がスキル作成作業をするための共通ルールです。
各スキルの個別指示書(01〜10)を実行する前に、このファイルを一度読んでください。

## スキルとは

Claude Code のスキルは、リポジトリの `.claude/skills/<スキル名>/SKILL.md` に置いた
Markdownファイルです。Claudeが作業中に該当する状況になると自動で読み込まれ、
過去のハマりどころを繰り返さないための知識・手順として機能します。

## ファイルの置き場所(厳守)

```
.claude/
  skills/
    <スキル名>/          ← 指示書に書いてあるスキル名。勝手に変えない
      SKILL.md           ← ファイル名は必ず大文字の SKILL.md
```

## SKILL.md の書式(厳守)

ファイルの先頭に必ず次の形式のフロントマターを付けます:

```markdown
---
name: スキル名(ディレクトリ名と完全一致させる)
description: どういう時に使うスキルかを1〜3文で。トリガーになるキーワードを含める。
---

(以下、本文)
```

ルール:
- `name` はディレクトリ名と完全一致(半角小文字とハイフンのみ)
- `description` は「いつ発動すべきか」が判定できるように具体的に書く。
  例:「iOS/iPad/Safariで音が鳴らない、AudioContextが動かない、と言われた時に使う」
- 本文は日本語。コード例はそのままコピペで動くものだけを載せる
- 各指示書に「SKILL.md に含める内容」が箇条書きしてあるので、**全項目を漏らさず**本文化する

## 作業手順(毎回同じ)

1. 個別指示書を最後まで読む
2. `.claude/skills/<スキル名>/SKILL.md` を作成する
3. 指示書の「完了条件」チェックリストを1つずつ確認する
4. 1スキル = 1コミット。コミットメッセージは以下の形式:

   ```
   スキル追加: <スキル名> — <一言で何のためか>
   ```

   例: `スキル追加: ios-audio-unlock — iOS音声問題を5分で解決するため`

5. 次の指示書に進む

## やってはいけないこと(全スキル共通)

- 指示書にないファイルを作らない・消さない(特に既存のHTMLファイルには触らない)
- スキル名・ファイルパスを変えない
- 英語で書かない(このリポジトリの利用者は日本語話者)
- 「たぶんこうだろう」でコード例を書かない。指示書に載っているコードだけを使う
- 複数スキルを1コミットにまとめない
